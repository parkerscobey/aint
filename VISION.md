# aint CLI vision

My agents are not the harness. They persist outside of a given harness lifecycle run, thanks to [Hizal](https://github.com/parkerscobey/hizal).

I can run my agent in Claude Code, OpenCode, Codex, OpenClaw, Pi - anywhere tool calling is supported.

My Agents aren't tied to a model provider or a harness provider.

I need a simple, easy to use tool that allows me to spin of an Agent in the harness of my choice.
